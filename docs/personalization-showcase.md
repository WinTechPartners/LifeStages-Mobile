# John 3:16 personalization showcase

Route: /personalization. Public; no email or Premium entitlement required for these fixed examples. Other content APIs retain their entitlement checks. This route bypasses member devotional and analytics providers, so sample selections do not change the visitor profile, subscription or church analytics.

32 saved example profiles: 2 genders × 2 countries (US/Vietnam) × 2 demo age ranges (18–24/55–65) × 4 selected circumstance combinations (none/baby/work issues/both). All user-facing text is English, including Vietnam. The showcase age range 55–65 deliberately follows the demo brief; it does not replace the product age ontology. Unselected parenting is unspecified, not evidence of no children. Baby examples at older ages do not assign a grandparent role from age.

Each bundle contains a Friendly Breakdown, two distinct modern fictional short stories, two poems (classic/free verse), and specific editorial notes. Examples were prepared with the production app's configured OpenRouter model using its content-format/voice constraints, with an additional controlled country and circumstance brief. They are stable showcase examples, not an exact replay of every production route and not real user records. Each story includes a saved opening illustration and a different midpoint illustration, generated through the production image endpoint and copied into public/showcase-stories. Image directions are metadata only and must never appear in narrative prose.

public/personalization-examples.json is checked in, has no credentials and generates no API calls when changing toggles. A/B comparison pins the currently selected example and compares with later toggles, across all three content types.
